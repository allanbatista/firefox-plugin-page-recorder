# Code of Conduct

This project follows the spirit of the Contributor Covenant.

## Expected behavior

- Be respectful and constructive.
- Focus on the code and the issue at hand.
- Keep discussions factual and concise.

## Unacceptable behavior

- Harassment, hate speech, and personal attacks.
- Doxxing, threats, or intimidation.
- Repeated disruption of issues or pull requests.

## Enforcement

Maintainers may remove content, close issues, or restrict access when needed to protect the project.

## Reporting

Report concerns privately through GitHub Security Advisories or direct maintainer contact.
